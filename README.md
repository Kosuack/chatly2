# Chatly — Discord-подобный мессенджер для веба

Без внешних зависимостей: нужен только Node.js 18+.

## Запуск

```bash
cd chatly
node server.js
```

Откройте http://localhost:3000 в двух разных браузерах (или в обычном и приватном окне), зарегистрируйте двух пользователей и проверьте чат в реальном времени.

Порт можно сменить: `PORT=8080 node server.js`.

## Возможности

- Регистрация и вход (пароли хранятся как scrypt-хеш)
- Серверы (гильдии) с приглашением по коду
- Текстовые каналы: создание, удаление (владелец)
- Личные сообщения между пользователями
- Сообщения в реальном времени (Server-Sent Events)
- Редактирование и удаление своих сообщений
- Ответы на сообщения
- Реакции-эмодзи (переключатель)
- Индикатор «печатает…»
- Статус онлайн / офлайн и список участников
- Подгрузка истории при прокрутке вверх
- Подсветка ссылок, `код`, **жирный**, *курсив*, блоки кода ```

Горячие клавиши: **Enter** — отправить, **Shift+Enter** — перенос строки, **Esc** — отменить ответ/редактирование, **↑** в пустом поле — редактировать последнее своё сообщение.

## Структура

```
chatly/
├── server.js          # HTTP API, SSE, хранение данных
├── data.json          # создаётся автоматически (все данные)
└── public/
    ├── index.html     # разметка
    ├── style.css      # тёмная тема в стиле Discord
    └── app.js         # клиентская логика
```

## Важно перед продакшеном

Это учебная основа, а не готовый продукт. Перед публикацией стоит добавить:

- **HTTPS** (обратный прокси, например nginx или Caddy)
- **Хранение в базе** (SQLite / PostgreSQL) вместо JSON-файла
- **Загрузку файлов и картинок** (сейчас только текст)
- **Ограничение частоты запросов** (rate limiting)
- **Срок жизни сессий** и выход со всех устройств
- **Роли и права** на сервере (сейчас только владелец и участники)
- **Личные сообщения через поиск пользователей** — сейчас нужно знать точное имя
- **Тесты** и логирование

## API (кратко)

| Метод | Путь | Описание |
|---|---|---|
| POST | `/api/register` | Регистрация |
| POST | `/api/login` | Вход |
| POST | `/api/logout` | Выход |
| GET | `/api/state` | Серверы, каналы, пользователи, онлайн |
| POST | `/api/guilds` | Создать сервер |
| POST | `/api/guilds/join` | Вступить по коду |
| DELETE | `/api/guilds/:id/members/me` | Покинуть сервер |
| POST | `/api/guilds/:id/channels` | Создать канал |
| DELETE | `/api/channels/:id` | Удалить канал (владелец) |
| POST | `/api/dms` | Открыть личный диалог по имени пользователя |
| GET | `/api/channels/:id/messages?before=` | История сообщений |
| POST | `/api/channels/:id/messages` | Отправить сообщение |
| PATCH | `/api/channels/:id/messages/:mid` | Редактировать |
| DELETE | `/api/channels/:id/messages/:mid` | Удалить |
| POST | `/api/channels/:id/messages/:mid/reactions` | Поставить/убрать реакцию |
| POST | `/api/channels/:id/typing` | Сигнал «печатает» |
| GET | `/api/events?token=…` | Поток событий (SSE) |
